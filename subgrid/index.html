Subgrid Playground

Cards in a row rarely have the same amount of content, so their titles, text and prices end up at different heights. Subgrid lets each card use its parent grid's rows (or columns) instead of making its own, so the parts line up across the row. Click any title or text to edit it and watch the row adjust.

Rows: line up the parts of each card

Click a title or text to edit · drag the corner ↘ to resize

How it works
  1. Each card spans 4 rows of the grid: image, title, text, price.
  2. grid-template-rows: subgrid makes the card use those shared rows instead of making its own.
  3. So the tallest title in a row sets that row's height, and every card's text and price start on the same line.
  4. Each Cell sits between the grid and the card, so it needs the same lines too.
  5. The catch: a container (container-type) can't be a subgrid, and Cell is a container by default. Subgrid cards need <Cell cellNormal>, and their content can't use container queries. Try the Cells are containers switch.

Columns: line up labels in a form

Subgrid works for columns too. Each field is its own row of label, input and hint. Without subgrid, every row sizes its label to fit, so the inputs start at different places. With grid-template-columns: subgrid, all fields share the form's columns: the longest label sets the width, and every input lines up.

CSS 
.form {
  display: grid;
  grid-template-columns: max-content 1fr max-content;
  gap: 10px 12px;
}

.form > .field {                    /* label, input, hint */
  display: grid;
  grid-column: 1 / -1;              /* span every column */
  grid-template-columns: subgrid;   /* share the form's columns */
}
